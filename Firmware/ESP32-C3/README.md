# ESP32-C3 DevKitM-1

Use the DevKitM-1 Micro-USB port and its built-in USB-to-UART bridge at 115200 baud. [Espressif DevKitM-1 guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c3/esp32-c3-devkitm-1/user_guide.html)

Build from the repository root with `pio run -e esp32-c3-devkitm-1`, or open this directory in PlatformIO. Keep this directory inside the FirmwareEmbed checkout.
