# ESP32-WROOM-32U

This 4 MB profile uses DIO at 40 MHz. Use the board’s USB-to-UART port at 115200 baud.

Build from the repository root with `pio run -e esp32-wroom-32u`, or open this directory in PlatformIO. Keep this directory inside the FirmwareEmbed checkout.
