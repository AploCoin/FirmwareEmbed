# ESP32-S3 N16R8

This profile uses 16 MB QIO flash and 8 MB octal PSRAM. Use the USB-to-UART port for UART0 at 115200 baud.

Build from the repository root with `pio run -e esp32-s3-n16r8`, or open this directory in PlatformIO. Keep this directory inside the FirmwareEmbed checkout.
