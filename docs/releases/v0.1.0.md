# FirmwareEmbed v0.1.0

Full retains eight board profiles, both mining modes, APLO1 configuration,
endpoint-specific CA validation and the persistent transaction journal.
APLO1 can service read-only requests during more of the TLS connection path.

Lite targets ESP8266 with 512 KiB and ESP32 with 1 MiB. Configure Wi-Fi, RPC,
CA and the wallet in a private DeviceConfig header before compiling. The
public Lite binaries are inactive templates. Both modes retain strict TLS
and a flash guard that blocks signing after an interrupted transaction until
the outstanding transaction is reconciled.

The USB manifest provides Install and Update. Update uses a single application
write and preserves the configuration or signing guard in its fixed region.
The release contains the exact source trees, locked library revisions, binaries,
manifest and SHA-256 checksums.

Current board profiles are experimental and available for community hardware
testing. CI verifies builds, flash boundaries, static RAM, TLS and recovery
regressions. Device testing is required to establish sustained mining, dynamic
heap and power-cut behavior for a specific board.
